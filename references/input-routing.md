# View Correction and Cleanup

Use this reference before editing. Choose one route silently. Correct the existing view
without converting it into another observation type or inventing unsupported space.

| Source | Route | Treatment |
|---|---|---|
| One dominant wall | FRONTAL | Make the camera plane parallel to that wall; true wall, opening, cabinet, and frontal-furniture verticals and horizontals should run parallel to the image edges |
| Two visible walls meeting at a corner | CORNER | Keep the corner and source depth; make true verticals vertical and make both horizontal families converge consistently toward their own vanishing points |
| Tight or incomplete vignette | PRESERVE_VIEW | Keep the crop and source depth; correct only roll, lens distortion, and distracting vertical convergence |
| Straight-down furnished home view | OVERHEAD | Keep a true orthographic view; align wall axes deliberately and preserve every major object in plan position |
| Floor plan or plan screenshot | PLAN | Deskew to a natural upright page orientation without changing topology, crop, openings, or symbols |
| Existing model, axonometric, elevation, or cutaway | PRESERVE_PROJECTION | Keep its observation type, geometry, cut planes, and visible content; correct only obvious scan or page skew |

For multiple views, use shared visible evidence only to understand the same interior.
Do not synthesize a new camera or reveal space that no source supports.

## Compact Scene Brief

Record only:

1. selected correction route and observation type;
2. locked architecture, openings, zones, and major furniture;
3. three to five identity anchors that must remain;
4. temporary small clutter that may be grouped, reduced, or omitted;
5. representative lived-in objects that must remain;
6. hidden or uncertain geometry that must not be invented.

Do not define a new focal point, lighting treatment, or design move.

## Curated-Base Edit

Use the following instruction, filling in only source-specific details:

    Edit this image as the same real interior using [ROUTE]. Complete only the
    route-specific geometric correction so the existing observation type reads
    deliberately. Preserve the room proportions, architecture, openings, functional
    zones, crop, major furniture position, orientation, scale, and identity. Preserve
    these identity anchors: [ANCHORS]. Group, reduce, or omit only this temporary small
    clutter: [CLUTTER]. Retain these representative lived-in objects: [LIVED-IN
    OBJECTS]. The result should feel real, lived-in, and lightly edited, not empty or
    staged. Do not convert the view type, reveal or invent hidden space, recrop, relight,
    remodel, move or replace furniture, or apply the final illustration style yet.

For an already tidy source, skip a separate base image and carry the same cleanup
boundary into the style edit.

Accept the base only when the route correction is coherent, the observation type and
crop are preserved, architecture and major furniture are unchanged, distracting small
clutter is moderately reduced, and several lived-in details remain.
