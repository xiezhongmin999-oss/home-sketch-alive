# Home Sketch Alive

把室内照片、平面图、立面图、俯视图、轴测图、剖切图或模型图，转换为带有自然叙事亮点的手绘建筑拼贴插画。

这个 Codex Skill 会先对原图做克制的整理与视角校正，再应用固定的白线色块风格。它以保留住宅原有空间关系为优先，不重新设计建筑、家具布局或动线。

## 视觉特点

- 扁平而醒目的色块
- 略带手绘感的暖白色线条
- 克制的纸张与拼贴纹理
- 以原图为主、参考图辅助协调的配色
- 一个由原场景支持的自然叙事亮点
- 保留空间比例、开口、功能分区和主要家具关系

当前版本只生成静态插画，不包含动画生成功能。

## 支持的输入

- 室内实景照片
- 建筑平面图与俯视图
- 室内立面图
- 轴测图与剖切图
- 实体或数字模型图像

Skill 会维持原图的观察方式：平面图仍是平面图，立面图仍保持正视，轴测图不会被改成透视场景，也不会补画原图中看不到的空间。

## 工作方式

1. 识别输入类型，并进行必要的轻度几何校正与杂物整理。
2. 锁定构图、视角、建筑关系和主要家具。
3. 按输入视角选择最多两张参考图，应用固定的色块、暖白线条和纸质拼贴风格。
4. 从原场景中选择一个自然、克制的叙事亮点。
5. 检查最终插画是否仍能明确辨认出原来的室内空间。

## 安装

将本仓库克隆或下载到 Codex 的 Skills 目录，并确保文件夹名为 `home-sketch-alive`：

```text
~/.codex/skills/home-sketch-alive/
```

## 使用

在 Codex 中上传一张室内图像，然后调用 Skill：

```text
使用 $home-sketch-alive 整理并校正我上传的室内场景，生成带自然叙事亮点的白线色块拼贴插画。
```

也可以在提示中补充你希望保留的家具、物品或场景特征，但不要要求改变建筑布局或转换为另一种观察视角。

## 设计边界

- 可以归纳或减少影响空间阅读的零碎杂物。
- 会保留少量能体现真实生活状态的代表性物品。
- 不移动、旋转、缩放或替换主要家具。
- 不改变墙体、门窗、开口、功能分区或交通关系。
- 不添加人物、说明文字、箭头或水印。
- 不把结果处理成写实渲染、传统建筑水彩或 CAD 风格。
